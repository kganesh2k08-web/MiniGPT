# 🤖 MiniGPT 

A modern AI chatbot built with **Python**, **Streamlit**, and **Google Gemini**.

---

## ✨ Features

- 🤖 Gemini 3.5 Flash Lite
- 💬 Conversation Memory
- 🎨 Modern Dark UI
- 📊 Chat Statistics
- 🗑 New Chat
- 💾 Export Chat
- ⚡ Fast Responses
- 🔒 Secure API using .env

---

## 🛠 Tech Stack

- Python

- Google Gemini API

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/minigpt.git
```

Go to the project folder

```bash
cd MiniGPT
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```env
GOOGLE_API_KEY=YOUR_API_KEY
```

Run the application

```bash
streamlit run streamlit_app.py
```
